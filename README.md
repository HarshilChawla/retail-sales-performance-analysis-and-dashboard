# retail-sales-performance-analysis-and-dashboard

## Overview
This project presents an interactive Excel dashboard designed to analyze retail sales performance across multiple dimensions such as time, region, and customer segment.
The focus of this project is on transforming raw transactional data into meaningful business insights using Excel-based analytical tools.

---

## Objectives
- Analyze sales and profit trends over multiple years
- Identify seasonal patterns at quarterly and monthly levels
- Compare regional and segment-level performance
- Evaluate profitability using relative contribution metrics

---

## Key Features
- Interactive Excel dashboard with slicers
- Year-wise, quarter-wise, and month-wise sales trends
- Sales vs Profit comparison across regions and segments
- Percentage contribution analysis (% of total sales vs % of total profit)
- Profitability deviation analysis to identify over- and under-performing areas
- Clean, executive-style dashboard layout

---

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Normal charts for dashboard visuals
- Slicers for interactivity
- Calculated fields and derived metrics
- Conditional formatting for numerical analysis

---

## Key Insights
- Overall sales show a consistent upward trend across years
- Q4 contributes the highest share of annual sales, indicating strong seasonality
- November and December consistently outperform other months
- Certain regions and customer segments contribute disproportionately to profit relative to their sales share, highlighting efficiency differences

---

## Notes
This project emphasizes Excel-based business analysis and dashboard design for non-technical stakeholders, complementing programmatic data analysis approaches.
